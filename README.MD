# matchum (맞춤)

[![PyPI](https://img.shields.io/pypi/v/matchum)](https://pypi.org/project/matchum/) [![OpenSSF Baseline](https://www.bestpractices.dev/projects/15483/baseline)](https://www.bestpractices.dev/en/projects/15483/baseline-1) [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23531936.svg)](https://doi.org/10.5281/zenodo.23531936)

로컬에서 동작하는 규칙 기반 한국어 맞춤법 검사 파이썬 라이브러리입니다.

- 외부 서비스에 접속하지 않는 방식으로 설계되었습니다.
- 파이썬 표준 라이브러리만 사용합니다.
- 기존 `py-hanspell` 코드를 import 한 줄만 바꿔 옮길 수 있는 호환 계층을 포함합니다.

> **개발 초기(0.x) 버전입니다.**
> 등록된 규칙에 해당하는 표기만 검출하며, 문맥을 이해하지 않습니다.
> 검출 누락과 잘못된 교정이 있을 수 있으므로, 결과는 참고용으로만 사용하고 최종 판단은 사용자가 직접 하시기 바랍니다.
> 버전이 올라가면서 API와 규칙이 예고 없이 바뀔 수 있습니다.

## 설치

```bash
pip install matchum
```

Python 3.9 이상에서 개발·테스트했습니다.

## 사용법

### 기본

```python
from matchum import check

r = check("몇일 뒤에 연락할께요. 나도 할수있다.")

r.checked   # '며칠 뒤에 연락할게요. 나도 할 수 있다.'
r.errors    # 3

for c in r.corrections:
    print(c.original, "→", c.suggestion, "|", c.message)
```

`Result`의 주요 속성은 다음과 같습니다.

| 속성 | 내용 |
|---|---|
| `original` | 원문 |
| `checked` | 교정문 (`ERROR` 수준만 반영, 아래 참고) |
| `corrections` | `Correction` 목록 (원문 위치, 원래 표기, 제안, 규칙 ID, 메시지, 수준, 분류) |
| `errors` | 검출 건수 |
| `as_dict()` | 위 내용을 dict로 반환 |

### 교정 수준

| 수준 | 의미 | `checked` 반영 |
|---|---|---|
| `ERROR` | 문맥과 관계없이 틀린 표기로 등록된 규칙 | 반영 |
| `WARNING` | 문맥에 따라 맞을 수도 있는 표기 (외래어, 이중 피동 등) | `check(text, apply_warnings=True)`일 때만 반영 |

### 사용자 설정

```python
from matchum import Checker, Category, WordRule

checker = Checker(
    ignore=["됬"],                       # 교정하지 않을 원문 표기
    disabled=["spacing.002"],            # 끌 규칙 ID
    categories=[Category.SPELLING],      # 특정 분류만 검사 (SPELLING / SPACING / STYLE)
).add_rule(WordRule("my.001", "어케", "어떻게"))

checker.check("어케 됬어").checked   # '어떻게 됬어'
```

### py-hanspell 호환 계층

```python
# from hanspell import spell_checker
from matchum import spell_checker

result = spell_checker.check("몇일 뒤에 봐요")
result.checked      # '며칠 뒤에 봐요'
result.as_dict()
```

반환 형식을 비슷하게 맞춘 것이며, 검사 결과는 원래 라이브러리와 다를 수 있습니다.
`words` 항목의 어절별 상태는 근사값입니다.

### 명령줄

```bash
matchum "몇일 뒤에 연락할께요"
matchum -f 원고.txt --json
echo "할수있다" | matchum
```

검출이 있으면 종료 코드 1, 없으면 0을 반환합니다.

## 규칙 구성 (0.2.0 기준, 규칙 약 770개)

| 분류 | 예시 |
|---|---|
| 되/돼·활용형 | 됬→됐, 치뤘다→치렀다, 담궜다→담갔다, 서슴치→서슴지 |
| 부사 | 곰곰히→곰곰이, 깊숙히→깊숙이, 여지껏→여태껏 |
| 명사·성어 | 윗층→위층, 눈꼽→눈곱, 순대국→순댓국, 실업율→실업률 |
| 어미 | 할께→할게, 하던지 말던지→하든지 말든지, 책이예요→책이에요 |
| 띄어쓰기 | 할수있다→할 수 있다, 너때문에→너 때문에, 하지않다→하지 않다, 보고싶다→보고 싶다 |
| 외래어 (WARNING) | 메세지→메시지, 컨텐츠→콘텐츠 |
| 문맥 의존 (WARNING) | 바램, 일부로, 잊혀지다, 뒤쳐지다 |

전체 목록은 `matchum.py`의 규칙 표에서 확인할 수 있습니다.

### 다루지 못하는 것

- 뜻으로 갈리는 표기 (로서/로써, 맞추다/맞히다, 든지/던지 등)
- 규칙에 등록되지 않은 오류
- 문장 단위의 문법·어순·문체

### 규칙 추가

1. 대부분의 규칙은 `matchum.py`의 사전형 규칙 표에 `(오표기, 교정어[, 옵션])` 한 줄을 넣어 만듭니다.
2. 오표기가 다른 정상 단어의 일부로 나올 수 있으면 `word_start` 또는 `exceptions` 옵션을 씁니다.
3. 문맥에 따라 맞을 수도 있는 표기는 `_CONTEXT` 표(WARNING)에 넣습니다.
4. 교정 메시지는 직접 작성합니다.
5. `test_matchum.py`의 `CASES`(교정 케이스)와 `CLEAN`(오탐 방지 케이스)에 예문을 추가합니다.
